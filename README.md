Neon Harbor is an original top-down 2D open-world crime game. Explore a living city on foot and by car, steal and drive cars through traffic and pedestrians, build a wanted level and outrun the Harbor PD, take on five story missions as getaway driver Mara Voss, fight with fists and a pistol, hunt hidden cash stashes, and save your progress — all in plain static files that run offline in a desktop browser, no build step and no network requests.

## Run it

```sh
node serve.ts
# then open http://localhost:8080
```
